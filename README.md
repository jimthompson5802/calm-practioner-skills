# CALM Practitioner Skills

This repository is a workspace for demonstrating and growing agent skills that help with tasks related to the [FINOS Common Architecture Language Model (CALM)](https://github.com/finos/architecture-as-code). It is intended as both a showcase and an incubation space for skill-driven workflows, prompts, examples, and supporting assets around the CALM open-source project.

CALM is a declarative approach for describing architectures as structured models. The materials in this repo focus on how AI assistants and agent skills can help with CALM-oriented work such as discovering architecture from code, creating or refining architecture models, and producing supporting documentation.

The repository is expected to expand over time. Architecture discovery is one example already captured here, but the broader goal is to build up a collection of reusable skills for a wider set of CALM-related tasks.

## What's here today

- Assistant-specific skill and prompt assets for CALM workflows across multiple environments
- An architecture-discovery proof of concept with recorded outputs in [examples/architecture-discovery](examples/architecture-discovery/README.md)
- Reusable templates for CALM-related architecture documents in [templates](templates/)


## Repository structure

- `.agents/`, `.claude/`, `.github/` - assistant-specific agent and skill definitions
- `examples/` - worked examples and captured outputs
- `templates/` - reusable supporting documents

## Notes

This repository is intentionally forward-looking. Some areas are lightweight today, and additional skills and examples are expected to be added as the repository evolves.
